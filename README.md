# zapisBot — Telegram-бот записи клиентов «Pulver Farbe»

Бот для записи на пескоструйную обработку и порошковую покраску металлических изделий.
Разработан в соответствии с ТЗ (см. файл `тз.txt`).

## Стек технологий

- **Язык:** Go 1.25+
- **Библиотека Telegram Bot API:** github.com/go-telegram-bot-api/telegram-bot-api/v5
- **База данных:** PostgreSQL (драйвер lib/pq)
- **Конфигурация:** переменные окружения (.env)
- **Миграции:** SQL-файлы в папке `migrations/`

## Архитектура

Проект модульный:

```
cmd/bot/          — точка входа
internal/config/  — загрузка конфигурации из .env
internal/database/— подключение к PostgreSQL, модели, репозиторий, миграции
internal/bot/     — FSM-автомат, сессии пользователей
internal/bot/handlers/ — клиентские и админские хендлеры
internal/services/ — калькулятор, заказы, расписание, уведомления
migrations/       — SQL миграции БД
systemd/          — файл сервиса для VPS
config/           — конфигурационные файлы
```

## Основные возможности (по ТЗ)

### Для клиентов:
- Регистрация (имя + телефон через `share_contact`)
- Конструктор заказа с 7 шагами:
  1. Категория услуги (пескоструй / покраска)
  2. Тип изделия (диски / детали авто / мото-рамы / суппорты / металлоконструкции)
  3. Параметры (радиус R13–R24 для дисков, габариты для остальных)
  4. Цвет RAL
  5. Покрытие (матовый / глянец)
  6. Дата и время (интерактивный календарь с учётом занятых слотов)
  7. Калькулятор стоимости + подтверждение
- Личный кабинет (активные и архивные записи)
- Отмена/перенос записи (не позднее чем за 24 часа)
- Лимит: не более 2 активных записей на один телефон

### Для администраторов:
- Админ-меню по команде `/admin` (доступ только по whitelisted Telegram ID)
- Просмотр сетки расписания (день/неделя)
- CRUD прайс-листа
- Настройка рабочих/выходных дней
- Мгновенные уведомления о новых записях

### Уведомления:
- Напоминание клиенту за 24 часа и за 2 часа до визита
- Мгновенное уведомление админу о новой брони

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/maksekak/zapisBot.git
cd zapisBot
```

### 2. Настройка конфигурации
```bash
cp .env.example .env
# Отредактируйте .env: укажите токен бота, ID администраторов, строку подключения к БД
```

### 3. Установка зависимостей
```bash
go mod download
```

### 4. Запуск в режиме разработки
```bash
go run ./cmd/bot/
```

### 5. Сборка
```bash
go build -o zapis-bot ./cmd/bot/
```

### 6. Развёртывание на VPS (systemd)
```bash
# Копирование файлов
sudo cp zapis-bot /opt/zapisBot/zapis-bot
sudo cp .env /opt/zapisBot/.env
sudo cp systemd/zapis-bot.service /etc/systemd/system/

# Активация сервиса
sudo systemctl daemon-reload
sudo systemctl enable zapis-bot
sudo systemctl start zapis-bot
```

## База данных

При первом запуске автоматически применяются миграции из папки `migrations/`.
Создаются таблицы: `admins`, `clients`, `services`, `price_list`, `schedule`, `orders`.

## Переменные окружения (.env)

| Переменная | Описание | Пример |
|---|---|---|
| `TELEGRAM_TOKEN` | Токен бота от @BotFather | `123456:ABC-DEF1234...` |
| `ADMIN_IDS` | Telegram ID администраторов через запятую | `123456789,987654321` |
| `DATABASE_URL` | Строка подключения к PostgreSQL | `postgres://user:pass@localhost:5432/db` |
| `BOT_NAME` | Название бота | `Pulver Farbe` |
| `WORK_HOUR_START` | Начало рабочего дня | `9` |
| `WORK_HOUR_END` | Конец рабочего дня | `18` |
| `TIME_SLOTS` | Доступные временные слоты | `9,10,11,14,15,16,17,18` |
| `BASE_PRICES` | Базовые цены по типам изделий | `диски:1500,детали авто:2000,...` |
| `COATING_*_SURCHARGE` | Надбавка за покрытие | `0` |
| `RADIUS_*_SURCHARGE` | Надбавка за радиус диска | `0` |

## Требования к серверу

- PostgreSQL 12+
- Go 1.25+
- VPS/VDS с доступом в интернет для вебхука/поллинга Telegram API
- Не менее 1 ГБ RAM, 1 CPU
